# Child Development RAG Skill

Этот Skill даёт доступ к базе знаний по детскому развитию, собранной из
Instagram-постов детских психологов и педагогов. База содержит информацию
об игрушках, играх, активностях и возрастных нормах для детей от 0 до 7 лет.

## Когда активировать

Активируй этот Skill если пользователь:

- Спрашивает про конкретную игрушку или игру (`"расскажи про пирамидку"`, `"что такое шнуровка"`)
- Запрашивает рекомендации по возрасту (`"что делать с ребёнком 2 лет"`, `"игры для детей 1.5 года"`)
- Задаёт общий вопрос о детском развитии (`"как развивать мелкую моторику"`, `"какие навыки в 3 года"`)
- Спрашивает о режиме дня, сне, самообслуживании ребёнка

Не активируй если пользователь спрашивает о медицинских диагнозах или лечении.

## Доступные MCP tools

### 1. `search_posts(query, top_k=5)`

Общий семантический поиск по базе Instagram-постов.
Использует Hybrid Retrieval (Dense + BM25 + RRF) с CrossEncoder-reranking и Query Rewriting.

**Когда использовать:** общие вопросы о детском развитии без конкретного возраста или игрушки.

```
Пример: search_posts("как развивать внимание у дошкольников")
```

### 2. `get_age_recommendations(age_years)`

Возвращает рекомендации по активностям, игрушкам и навыкам для конкретного возраста.
Принимает возраст в годах (можно дробное: `1.5` = 1 год 6 месяцев).

**Когда использовать:** пользователь упоминает конкретный возраст ребёнка.

```
Пример: get_age_recommendations(2.0)   → рекомендации для детей 2 лет
Пример: get_age_recommendations(0.5)   → рекомендации для детей 6 месяцев
Пример: get_age_recommendations(3.5)   → рекомендации для детей 3.5 лет
```

### 3. `get_toy_info(toy_name)`

Ищет информацию о конкретной игрушке или игре: возраст, как использовать, какие навыки развивает.

**Когда использовать:** пользователь называет конкретную игрушку или игру по имени.

```
Пример: get_toy_info("пирамидка")
Пример: get_toy_info("шнуровка")
Пример: get_toy_info("рыбалка червячки")
Пример: get_toy_info("мозаика шестигранная")
```

## Алгоритм выбора tool-а

```
Вопрос пользователя
  ├── содержит название игрушки/игры?
  │     → get_toy_info(toy_name)
  │
  ├── содержит конкретный возраст?
  │     → get_age_recommendations(age_years)
  │
  └── общий вопрос о развитии?
        → search_posts(query)
```

## Примеры использования

| Вопрос пользователя | Tool | Аргумент |
|---|---|---|
| "расскажи про пирамидку" | `get_toy_info` | `"пирамидка"` |
| "что делать с ребёнком 2 лет" | `get_age_recommendations` | `2.0` |
| "игры для ребёнка 1 год 6 месяцев" | `get_age_recommendations` | `1.5` |
| "как развивать мелкую моторику" | `search_posts` | `"развитие мелкой моторики у детей"` |
| "какие настольные игры в 3 года" | `get_age_recommendations` | `3.0` |
| "что такое виммельбух" | `get_toy_info` | `"виммельбух"` |
| "как научить ребёнка одеваться" | `search_posts` | `"навыки самообслуживания одевание"` |

## Формат ответа

После получения результата от tool-а:

1. Процитируй ключевые факты из поля `answer`
2. Укажи возрастные рамки если они есть
3. Добавь практические советы из поля `recommendations` если доступны
4. Отвечай на языке пользователя (русский)

Если tool вернул `found: false` или ответ содержит "информации нет" —
честно сообщи что данных по этой теме в базе нет.

## Источники данных

База знаний построена на Instagram-постах:
- **astrovskaya_irina** — детский психолог, специалист по сну и развитию
- **kuznetsova_neuropsy** — нейропсихолог, специалист по играм и игрушкам

Данные собраны через Playwright-скрапер (`instagram_scraper3.py`),
обработаны и проиндексированы в ChromaDB с эмбеддингами `intfloat/multilingual-e5-large`.
